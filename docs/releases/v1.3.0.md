# Release v1.3.0

`v1.3.0` adds opt-in model metadata enrichment for Bifrost and LM Studio. Discovery remains based on the standard OpenAI-compatible `/v1/models` endpoint; provider-specific metadata is requested or interpreted only when explicitly configured.

## New

### Bifrost Model Metadata Enrichment

Enable Bifrost metadata enrichment for a provider that returns Bifrost model records from `/v1/models`:

```json
{
  "provider": {
    "bifrost": {
      "options": {
        "modelsDiscovery": {
          "enabled": true,
          "modelInfoFormat": "bifrost"
        }
      }
    }
  }
}
```

The plugin reads Bifrost metadata from each discovered model record without making an additional request. It maps context, input, and output token limits; supported input and output modalities; and prompt and completion pricing.

Bifrost modality values are normalized for OpenCode, including uppercase values and `SPEECH` as `audio`. Prices returned in USD per token are converted to OpenCode's USD per million tokens format. A Bifrost `normalized_name` is used only when `smartModelName` is enabled.

### LM Studio Model Metadata Enrichment

Enable LM Studio metadata enrichment for LM Studio 0.4.0 or later:

```json
{
  "provider": {
    "local": {
      "options": {
        "modelsDiscovery": {
          "enabled": true,
          "modelInfoFormat": "lmstudio"
        }
      }
    }
  }
}
```

Discovery uses `/v1/models`, then enrichment reads LM Studio's native `/api/v1/models` inventory. Set `modelInfoEndpoint` to override the metadata endpoint.

Models are matched by their exact LM Studio `key`. The enricher maps display names, vision support, tool-use support, reasoning support and variants, and context limits.

LM Studio does not report a separate output token limit. Enriched models therefore set `limit.output` to `0`, which satisfies OpenCode's configuration schema while preserving OpenCode's default or configured output-token fallback rather than treating the context window as an output limit.

## Changed

### Metadata Enrichment Configuration

`modelInfoFormat` now supports the following explicit provider-scoped formats:

```text
bifrost
litellm
lmstudio
models.dev
vllm
```

`modelInfoEndpoint` is documented for LiteLLM and LM Studio endpoint overrides. The `/models-discovery:config` command also includes both new formats and the optional endpoint setting.
